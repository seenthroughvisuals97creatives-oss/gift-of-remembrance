A GIFT OF REMEMBRANCE: where to change things
==============================================

Open index.html in a browser to see the site. To put it online, upload the whole folder
(for example to GitHub Pages) and keep the folder structure as it is.

WHERE THE WORDS LIVE (each file is small and does one job)
  js/beginner.js     All Beginner questions, answers and where each answer leads
  js/vibrations.js   The list of vibrations (name, how it feels, element, tone)
  js/months.js       The 12 months, their signs, key phrases, gifts and edges
  js/starseed.js     The Starseed pop-up (explains a star and a seed)
  js/worldwithin.js  The World Within pop-up
  js/community.js    The Pure Love Network of States pop-up
  js/links.js        Every web address (Starseed, World Within, network, feedback, support)
  js/intro.js        The typed subtitle

THE MACHINERY (you should not need to touch these)
  js/journey.js      The pop-up that shows one question at a time
  js/app.js          Connects the intro, welcome box, landing page, sharing and surprise notice
  js/session.js      Keeps the name, month and colour while the tab is open
  js/particles.js    The moving dots, lines and hearts in the visitor's colour
  css/main.css       Colours, fonts and layout

BEFORE YOU PUBLISH
  1. Fill in js/links.js (empty links hide their buttons).
  2. Replace assets/pure-love-logo.svg with your round logo (same file name, or edit index.html).
  3. In index.html, change og:image to the full web address of og-image.png
     (for example https://yourname.github.io/gift/og-image.png) and add an og:url line.
     This is the picture shown when the link is shared.
  4. Replace the first-draft words in months.js, starseed.js, worldwithin.js and community.js.

PRIVACY
  The name, month and colour stay in the visitor's browser tab only. Nothing is sent or saved anywhere.
  You will not see anyone's answers. To count visits, add a privacy-friendly analytics tool later.
